# Charter Life Demo

Offshore fishing and charter boat sim.

- **Play in the browser:** https://wolfarka91816.github.io/charter-life/
- **Android app (APK):** https://wolfarka91816.github.io/charter-life/download.html  (or straight to the file: https://github.com/wolfarka91816/charter-life/releases/download/android-latest/CharterLife-demo.apk)

## How the Android app is made
GitHub builds it for you. Every push to `main` runs `.github/workflows/android.yml`, which wraps the game in an Android shell
(Capacitor), signs it, and publishes `CharterLife-demo.apk` to the **android-latest** release. Takes about 5 minutes.
To build by hand: Actions tab > Build Android APK > Run workflow.

The signing key `android-app/charterlife-demo.jks` is a demo-only key kept in the repo on purpose so every build is signed the same way
and installs over the previous one without losing saves. It is not a secret and must not be reused for anything else.
