# Charter Life Demo (download page)

Public download site for the Charter Life demo. Hosted with GitHub Pages: the page at the root is the download page, and `play/` is the installable app.

Give players this one link (replace USER and REPO):

    https://USER.github.io/REPO/

## Updating the demo
1. In the game project run `python3 build.py demo` (it also rebuilds `builds/site_demo/`).
2. Replace the files in this repo with the new contents of `builds/site_demo/` and commit.
3. Pages redeploys in a minute. Installed apps pick up the new version the next time they are opened online.

Generated by build.py. Do not edit by hand.
