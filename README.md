# Charter Life — Demo

An offshore fishing and charter boating game, playable right in your phone's browser.

**Play:** https://wolfarka91816.github.io/charter-life/

Open the link, tap **Play**, and go fishing. No download needed.
This is the free demo (level cap, two regions). The full game is coming later.

**Install it as an app:** open the link on your phone and tap the **📲 Install Charter Life** button at the top
(or the browser menu → **Install app** / **Add to Home screen**). It gets its own icon, opens full-screen, and works offline.
